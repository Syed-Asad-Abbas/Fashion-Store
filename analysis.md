2. Typography System
As previewed in 

typography.png
 and available in your 

fonts/
 directory:

Beatrice Font Family (Display / Headline / Deck / Standard):

Weights: Light, Regular, Medium, Semibold, Bold, Extrabold, Black (with matching italics).
Usage: Used for high-impact editorial typography, major headings, hero titles ("NEW COLLECTION", "NEW THIS WEEK", "XIV COLLECTIONS 23-24", "OUR APPROACH TO FASHION DESIGN", "PRODUCTS", "CHECKOUT", brand monogram "XIV").
Character: High-contrast, avant-garde modernist fashion serif with inverted-contrast gestures giving a high-end luxury editorial feel (Acne Studios / Zara Studio / Jacquemus aesthetic).
Source files: Available in the project under 

fonts
 (.otf and .ttf formats).
Inter Font Family (Grotesque Sans-Serif):

Weights: Regular (400), Medium (500), SemiBold (600), Bold (700).
Usage: Body text, navigation links, search placeholders, filter options, size pill labels, buttons, pricing, cart counters, and input fields.
Character: Clean, hyper-legible, geometric sans-serif that balances the expressive Beatrice headings with functional UI clarity.
